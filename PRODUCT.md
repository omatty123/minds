## Platform
web

## Stack
Static HTML, CSS and JavaScript; GitHub Pages, following the user's standing website instructions. No build dependency is needed.

## Users
Potential faculty collaborators considering MIND(s) as a future First-Year Studies theme at Lawrence University.

## Product Purpose
Develop an interdisciplinary model syllabus and an expanding learning bank on minds. Support a long-term faculty proposal with teachable works and precise sources.

## Capabilities and Constraints
Public website authorized October 10, 2026. Searchable, filterable research bank; model syllabus; rationale; collaboration route. Preserve the user's four overarching questions. Do not generate additional discussion questions. Initial focus: Michael Levin, Mark Solms, Cameron Berg (https://x.com/camhberg). Include neuroscience, philosophy, Asian Studies, music, poetry, art, psychology and sport. Research records distinguish empirical studies, theoretical arguments, preprints and cultural works. The current research pass is a selected starting collection, not an exhaustive inventory. No automatic research schedule requested.

## Operating Context
The 2024 institutional announcement gives Water a four-year run beginning fall 2024. Fall 2028 is an inference, not a confirmed replacement date. Theme-selection process and deadlines remain unverified. The site is a faculty proposal, not an adopted University curriculum. No personal correspondence, internal personnel opinions or unconfirmed endorsements may be published.

## Brand Commitments
MIND(s). Sleek, professional journalism design in black, white and red. Compact useful headers, natural heading wraps, readable mobile layouts. User chose direct code construction. NO SERIF: all typography must be sans-serif, including headings, wordmarks, print and SVG text. Only an explicit user request permits an exception.

## Product Principles
Treat disciplines as intellectual contributors. Distinguish observation, interpretation and speculation. Build a feasible common curriculum. Link original sources. Make revision easy over several years.
